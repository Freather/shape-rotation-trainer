# UI 개선 계획

## 지금 문제
1. 기본값 그대로인 모양: 둥근 알약 버튼, 파스텔 면 색, 흔한 파란색 강조. 어디서 본 듯한 "AI가 만든 화면" 느낌이 난다.
2. 문구가 길고 기계적이다. 줄표(—)로 이어 붙인 문장, 괄호 속 설명이 많다.
3. 화면마다 중요한 것이 무엇인지 드러나지 않는다. 샌드박스 오른쪽 패널에 버튼이 한꺼번에 쏟아져 있다.
4. 보기에서 "내가 고른 답"과 "정답"을 색으로만 구분한다.
5. 휴대폰에서 3D 도형이 화면을 꽉 채우고 축 표시가 잘린다.

## 방향: 시험지처럼
- 흰 종이, 검은 글씨, 얇은 선. 모서리는 거의 각지게(4px), 그림자 없음.
- 강조색은 하나만 쓴다(먹색 버튼 + 정답 초록, 오답 빨강).
- 면 색은 기본으로 끄고, 면 방향에 따라 회색 음영을 넣어 입체감을 준다. 색은 설정에서 켤 수 있다.
- 글꼴은 Pretendard 하나로 통일하고 크기 단계를 정한다.

## 할 일
| 영역 | 바꿀 내용 |
|---|---|
| 상단 | 알약 탭 → 밑줄 탭, 앱 이름 작게 |
| 문제풀이 설정 | 유형 드롭다운 → 묶음별 카드 목록(입체 회전 / 전개도 / 평면), 레벨은 1~5 버튼 |
| 문제 화면 | 시험지 배치, 보기 번호 크게, 채점 후 "내 답" "정답" 글자 표시 |
| 샌드박스 | 오른쪽 패널을 탭 3개(회전 / 펼치기 / 면 편집)로 나눔. 회전 버튼은 표(앞·위·오른쪽 × 시계·반시계·180°). 재생 막대는 3D 화면 바로 아래 |
| 휴대폰 | 화면 비율에 맞춰 카메라 거리 조절, 보기 2~3열 |
| 문구 | 해요체, 짧게, 줄표 금지, 괄호 최소화 |
